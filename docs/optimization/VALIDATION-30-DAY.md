# 30-day check

These numbers are experiments for the owner to count. They are not a forecast and not a promise.

Count from the day production contains this branch, for about 30 days:

| Signal | Experimental target |
| --- | --- |
| External visitors, with internal traffic removed | 100 |
| Visits that start a lab (`lab_start`) | 20 |
| Distinct pieces of external feedback (issue, mail, or a public reply) | 5 |
| Non-branded queries with at least one impression | 10 |

Also record, without a target: indexed pages, impressions, organic clicks, landing pages, lab completions, completion rate, prompt copies, chapter clicks from guides, and referrals from any community post the owner actually published.

## How to read the result

| What you see | What to do next |
| --- | --- |
| No impressions | Check Search Console indexing and the submitted sitemap before writing more pages. |
| Impressions, few clicks | Compare the query with the title and description of the landing URL. |
| Visitors, few lab starts | The homepage paths or the first paragraph are not making the labs obvious. |
| Lab starts, few completions | Use the lab itself: the challenge steps, errors, and phones. Do not add a fourth lab yet. |
| Completions, little traffic | Distribution is the constraint. Use the unpublished drafts only if the owner chooses a community and follows its rules. |

Do not add chapters only to make the sitemap longer. The next page should answer a question the 30-day queries actually show.
