## Glossary

<T label="Glossary">

| Term | In one line |
| --- | --- |
| Block / hash | A unit of transaction records, and a content "fingerprint" |
| Node / consensus | A computer that independently validates data, and the rules for jointly deciding which history is accepted |
| Proof of stake (PoS) | Ethereum's consensus: validators stake ETH and propose and attest to blocks by protocol rules |
| Wallet / private key | A signing tool, and the secret that controls an address |
| Seed phrase | A list of words that restores a whole wallet; even more sensitive than one key |
| Address | A public "house number" you can share |
| Gas / fee | The unit of execution work; fee = gasUsed × effective gas price |
| Base fee / tip | The part that is burned, and the part paid to the validator |
| Nonce | An account's transaction counter, starting at 0 and rising with each mined transaction |
| Mempool | Where broadcast transactions wait for inclusion; a hash does not prove they are on-chain |
| EVM / smart contract | The environment that runs on-chain programs, and rule code deployed on-chain |
| Revert | Undoing all state changes of an execution when a check fails; gas is still paid |
| `eth_call` / simulation | Read-only execution: no signature, no cost, no change to the chain |
| ERC-20 | The common interface standard for fungible tokens |
| allowance / approve | An amount a spender may use, and the function that sets it; not a payment |
| transferFrom / burnFrom | A spender moving or burning tokens within the allowance |
| Burn | Destroying tokens: lowers both a balance and total supply |
| Atomicity | All operations in one transaction take effect together or not at all |
| Proxy / implementation | A stable entrance, and the replaceable logic behind it |
| ProxyAdmin | The only admin contract that can switch a proxy's implementation |
| initialize | The run-once setup function that replaces the constructor in upgradeable contracts |
| Storage layout | Where state variables sit in storage slots; upgrades may only append, never reorder |
| Redenomination / scale | Changing the unit of account; in UBOX V3, 10,000 old = 1 new |
| Dust | A remainder too small to show after conversion |
| Unit / fuzz / invariant tests | Specific cases / random inputs / properties after any call sequence |
| Fork / Sepolia | A local copy of chain state for simulation / a public testnet |
| Source verification / exact match / match | Proving source compiles to the on-chain bytecode; metadata also matches / only bytecode matches |
| GUID | A queue ID returned after submitting verification, not a success mark |
| Faucet | A service that gives out free test coins |

</T>
