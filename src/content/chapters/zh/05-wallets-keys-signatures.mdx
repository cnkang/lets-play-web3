<p class="lead"><Term id="wallet">钱包</Term>主要保管的是「签名的能力」，而不是把代币放在某个软件里的抽屉。</p>

## 代币其实不在钱包里

银行卡支付时，是银行验证你的身份和账户权限。在<Term id="ethereum">以太坊</Term>这类网络里，普通账户通过<strong><Term id="private-key">私钥</Term></strong>生成<strong><Term id="signature">数字签名</Term></strong>，网络根据签名验证这笔<Term id="transaction">交易</Term>确实得到了授权。

- **地址**更像公开的收款账号，可以放心告诉别人。
- **私钥**更像不可重置的最高权限：谁拿到它，谁就能以这个地址的名义签任何交易。
- 你的代币余额其实记在**链上的合约里**（例如 <Term id="erc20">ERC-20</Term> 合约里的一张余额表），钱包只是帮你读出来、并在你同意时替你签名。

<Figure name="wallet-flow" n="2" alt="五个步骤：钱包用本地私钥签名；已签名交易；RPC 节点校验并放入内存池；验证者打包进区块；区块浏览器显示网络、状态、发送方、接收方、日志、区块和哈希。">
签名后的交易被广播到网络，经节点检验、被验证者打包进区块，再由区块浏览器观察。私钥自始至终不离开钱包。
</Figure>

## 四种操作，风险完全不同

- **连接钱包**：让网站知道你的某个地址。它本身不会自动转走代币。
- **签署消息**：可能只是一个登录声明，也可能构成有风险的授权。**一定要读懂再签**。
- **发送交易**：会触发链上状态变化，通常要付 <Term id="gas">gas</Term> 手续费。
- <strong>导出<Term id="seed-phrase">助记词</Term>或私钥</strong>：意味着拿到它的任何人，都可能控制该地址的全部资产。正规网站几乎从不需要你这么做。

## 助记词、私钥和 API 密钥

它们名字里都可能有「key」，但风险完全不同：

<T label="私钥、助记词、API 密钥与地址的区别">

| 名称 | 能做什么 | 泄露了会怎样 |
| --- | --- | --- |
| 私钥 | 签名交易：转账、部署合约、授权代币 | 别人可以花掉这个地址上的全部资产 |
| 助记词（通常 12 或 24 个单词） | 恢复整个钱包（可能含多把私钥） | 比单把私钥更严重：整个钱包被接管 |
| API 密钥（例如 Etherscan 的） | 以你的名义调用某个网站的接口 | 一般不能转走资产，但会被用光额度或冒名调用 |
| 地址 | 公开的「门牌号」 | 不是秘密；被引导到假地址才是风险 |

</T>

附录 B 会专门讲 <Term id="api-key">API 密钥</Term>怎么申请、怎么保管。

## 本书实验的做法

- 账户 A、B 都是**本地新生成**的一次性测试账户，从没有导入任何真实钱包的助记词，也从没有在<Term id="mainnet">主网</Term>上使用。
- 私钥只存放在本地目录里（不会上传到公开代码仓库；目录权限 700、文件权限 600），从不打印、从不写入公开记录或本书。
- 广播脚本会检查账户的 ETH 余额**不超过 0.1 ETH**，防止误用一把可能带有主网资金的密钥。

这个余额上限只是实验脚本的一道附加检查，**不能证明同一把密钥在其他网络没有资产**。隔离要靠新建专用测试账户，并在操作前核对网络。阅读本书不需要创建或连接钱包。
