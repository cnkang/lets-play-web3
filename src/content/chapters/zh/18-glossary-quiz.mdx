## 术语速查

<T label="术语速查表">

| 术语 | 一句话理解 |
| --- | --- |
| 区块 / 哈希 | 交易记录的单元，以及内容的「指纹」 |
| 节点 / 共识 | 独立验证数据的计算机，以及共同决定接受哪条历史的规则 |
| 权益证明（PoS） | 以太坊的共识机制：验证者质押 ETH，按协议规则提议和证明区块 |
| 钱包 / 私钥 | 签名工具，以及控制一个地址的秘密 |
| 助记词 | 一组单词，可恢复整个钱包；比单把私钥更要紧 |
| 地址 | 公开的「门牌号」，可以告诉别人 |
| Gas / 手续费 | 执行的计量单位；手续费 = gasUsed × 有效气价 |
| base fee / tip | 被销毁的基础费，以及给验证者的小费 |
| nonce | 账户的交易序号，从 0 开始，每笔被打包的交易加一 |
| 内存池（mempool） | 交易被打包前等待的地方；那里的哈希还不是事实 |
| EVM / 智能合约 | 执行链上程序的环境，以及部署在链上的规则代码 |
| revert（回滚） | 条件失败时撤销本次执行的全部状态改动；gas 仍要付 |
| `eth_call` / 模拟 | 只读执行，不签名、不花钱、不改链 |
| ERC-20 | 可互换代币的常见接口标准 |
| allowance / approve | 可代扣额度，以及设置它的函数；不是付款 |
| transferFrom / burnFrom | 被授权者在额度内转走或销毁代币 |
| burn | 销毁：同时减少余额和总供应 |
| 原子性 | 一笔交易里的操作要么全部生效，要么全部不生效 |
| 代理 / 实现 | 稳定的交互入口，以及可替换的执行逻辑 |
| ProxyAdmin | 唯一能让代理更换实现的管理合约 |
| initialize | 可升级合约里代替构造函数、只能执行一次的初始化函数 |
| 存储布局 | 状态变量在存储槽里的位置；升级时只能追加、不能重排 |
| 面额重标 / scale | 改变记账单位；UBOX V3 中 10,000 旧 = 1 新 |
| 粉尘（dust） | 换算后显示不出来的零头 |
| 单元 / Fuzz / Invariant 测试 | 具体用例 / 随机输入 / 任意调用序列后的性质 |
| Fork / Sepolia | 在本地复制链状态做模拟 / 公共测试网 |
| 源码验证 / exact match / match | 证明源码能编出链上字节码；元数据也一致 / 仅字节码一致 |
| GUID | 提交验证后的排队编号，不是成功标志 |
| 水龙头（faucet） | 免费发放测试币的服务 |

</T>
